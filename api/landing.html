Market Data API

A portfolio project: crypto, stocks and macro data flowing through a pipeline on GCP.

Crypto, stocks and macro come in daily from three public APIs, land in BigQuery, and are served through SQL views to a dashboard and an API.

Daily prices are collected from public APIs, stored in BigQuery, and served through the dashboard and endpoints below. This is a portfolio project, not financial advice.

Dashboard

Open the full dashboard in a new tab (recommended on phones).

Endpoints

  • GET /api/market-snapshot: latest price for each tracked crypto and stock, grouped by category.
  • GET /api/volatility/{symbol}?days=30: daily and annualized volatility, price range and price change over the last N days (1 to 365).
  • /docs: interactive documentation where you can try each endpoint.

Valid symbols: BTC, ETH, SOL, SPY, QQQ, DIA.

What is tracked, and why

  • Crypto (BTC, ETH, SOL): the three best-known coins.
  • Stocks (SPY, QQQ, DIA): broad market, tech/growth and blue-chip, so volatility comparisons are more interesting.
  • Macro (FEDFUNDS, DGS10): collected daily and stored; not yet exposed in the API or dashboard.

Data sources

CoinGecko (crypto), Alpha Vantage (stocks) and FRED (macro). Everything runs on Cloud Scheduler, Cloud Run and BigQuery.

Known limitations

  • Stock volatility counts weekdays only; market holidays still appear as zero-return days.
  • Volatility describes the past window only. It is not a forecast.
  • The first request after a quiet period can take a few seconds (Cloud Run cold start).
